# EventSphere User Guide

1. Use **Events** to create and plan an event, then allocate venues and resources.
2. Use **Registration** to create a participant registration and digital ticket.
3. Use **Check-in** on event day to verify a QR ticket and update attendance.
4. Use **Vendors** to onboard vendors, assign them to an event, and capture ratings.
5. Use **Operations** for per-event finance, sponsorships, expense approvals, and reminders.
6. Use **Operations → Analytics** for KPIs, comparisons, reports, utilization, and forecast guidance.
7. Use **Feedback Insights** for feedback sentiment and participant outcomes. Participants use **Participant Hub** with their registration ID.
